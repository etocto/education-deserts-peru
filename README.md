# Education deserts after university licensing in Peru

Code and data for the article *Education Deserts after University Licensing: Geographic and Field-Specific Access to Undergraduate Programs in Peru* (Tocto-Cano, Condori-Coaquira, Mamani Morales and Humpiri-Flores; submitted to *Education Sciences*).

The pipeline measures university deserts for 537,451 final-year secondary students by field of study (nine ISCED-F families), using straight-line distance (60 km) and road and river travel time (90 min). It then:

- estimates the territorial correlates of deserts (negative binomial, SLX, SAR/SEM, Conley standard errors, random forest with SHAP);
- estimates their association with higher education attendance (WLS with department fixed effects and Oster bounds);
- simulates the effect of the SUNEDU license denials and separates structural, topographic and policy-induced deserts;
- solves a maximal covering location model with an illustrative cost-effectiveness analysis.

> Code comments and file names are in Spanish; this README is in English.

## Repository structure

```
config.yaml        all parameters (radii, speeds, thresholds, cost assumptions with sources)
run_all.py         runs the pipeline (all steps or selected ones)
requirements.txt   Python dependencies
src/               numbered scripts (00 to 14) and utils.py
datos/raw/         official public source files, each folder with LEEME_fuente.txt (URL, date, filters, checks)
datos/manual/      manual corrections of field classification and branch-campus locations
datos/interim/     intermediate files
datos/processed/   only the travel-time datasets (the rest is regenerated by the scripts)
salidas/           tables (CSV), figures, maps and model outputs reported in the article
```

## Data sources

| Source | Content | Terms |
|---|---|---|
| SUNEDU open data (cut-off 28 Aug 2024) | licensed undergraduate programs with coordinates; institutional licensing; 2018 university identity cards | Peruvian open data (datosabiertos.gob.pe) |
| Minedu, ESCALE, 2025 Census of Education | 15,700 secondary schools, enrollment by grade, 934 non-university institutes | Peruvian open data |
| INEI | 2018 district poverty map; 2017 Census district tabulations (REDATAM); district boundaries | Peruvian open data |
| OpenStreetMap via Geofabrik | road and river network of Peru (extract downloaded 27 Sep 2026) | © OpenStreetMap contributors, ODbL 1.0 |

The OSM extract (`peru-latest.osm.pbf`, ~245 MB, SHA-256 `3e647828fba5b05150ec15c50926a679064ba6956160ad8a91f5b86508a4467e`) is not stored in the repository. Because OSM changes every day, the travel-time results are stored in `datos/processed/` (`tiempos_colegios.csv`, `accesibilidad_tiempo_distritos.csv`, `sensibilidad_colegios.csv.gz`). With these files every table and figure can be reproduced exactly without downloading OSM. Re-running steps 4b and 4d downloads the current extract, so results may differ slightly.

## How to run

Python 3.10 or later.

```bash
pip install -r requirements.txt
python run_all.py            # all steps except 4b and 4d (a few minutes; step 8 is the slowest)
python run_all.py 4 5 10     # selected steps only
python run_all.py 4b 4d      # optional: rebuild travel times from a fresh OSM extract (30-60 min)
```

| Step | Script | Output used in the article |
|---|---|---|
| 1, 1b | `01_oferta_universitaria.py`, `01b_filiales_denegadas.py` | licensed supply 2024; supply of denied universities 2018 |
| 2, 3 | `02_demanda_escolar.py`, `03_censo2017_covariables.py` | final-year students by school; district covariates |
| 4 | `04_accesibilidad.py` | distance deserts by field (Figure 1, Table 2) |
| 4b, 4d, 4h | `04b_tiempos_viaje.py`, `04d_sensibilidad_tiempos.py`, `04h_robustez_tiempos.py` | travel-time deserts, sensitivity and stability (Table 2, Table A1) |
| 4c, 4e, 4g | `04c_efecto_licenciamiento.py`, `04e_gestion.py`, `04g_relicenciadas.py` | effect of license denials, public vs. private supply, institutes, relicensed universities (Figure 4, Table 6) |
| 5, 10, 10b | `05_modelos_conteo.py`, `10_asistencia_moran.py`, `10b_espacial_robustez.py` | count models, attendance models, spatial and Oster robustness (Tables 4, 5, A2-A5) |
| 6 | `06_ml_explicable.py` | random forest, XGBoost and SHAP with spatial cross-validation (Figure 3b) |
| 7 | `07_tipologia_clusters.py` | district typology (Table 3, Figure 2) |
| 8, 14 | `08_localizacion_optima.py`, `14_costos.py` | location model and cost-effectiveness (Table 8, Figure 5) |
| 13 | `13_taxonomia_desiertos.py` | structural, topographic and policy-induced deserts (Table 7) |
| 9, 11, 12 | `09_mapas_figuras.py`, `11_figuras_modelos.py`, `12_resumen_grafico.py` | maps, figures and graphical abstract |
