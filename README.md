# Field-specific university deserts and their origins in Peru

Code and data for the article *Field-Specific University Deserts and Their Origins: Remoteness, Topography and Licensing in Peru* (Tocto-Cano, Condori-Coaquira, Mamani Morales, Humpiri-Flores and Mamani-Pari; submitted to *Higher Education Policy*).

The pipeline measures university deserts for 537,451 final-year secondary students in nine fields of study (adapted from ISCED-F 2013), using straight-line distance (60 km) and road and river travel time (90 min) calibrated against Google Maps. It then:

- separates three mutually exclusive origins of deserts: structural (remoteness), topographic and licensing-related, using SUNEDU's 2018 identity-card register to reconstruct the supply of the 45 universities denied a licence, with and without the six universities relicensed in 2024-2026;
- estimates the territorial correlates of deserts with fractional logit models (between and within departments), with count models, Conley standard errors and a random forest as secondary analyses;
- compares public and private providers and non-university institutes;
- documents the calibration of travel times, an independent verification of 20 schools, a terrain check of topographic deserts and sensitivity analyses (radius, speeds, rivers, region-specific speed factors, location of denied branches).

> Code comments and file names are in Spanish; this README is in English.

## Repository structure

```
config.yaml        all parameters (radii, speeds, calibration factor, thresholds)
run_all.py         runs the pipeline (all steps or selected ones)
requirements.txt   Python dependencies
src/               numbered scripts (00 to 38), utils.py and red_liviana.py (low-memory road network)
datos/raw/         official public source files, each folder with LEEME_fuente.txt (URL, date, filters, checks)
datos/manual/      manual inputs: field corrections, branch locations, Google Maps validation times,
                   denial resolutions of the 45 universities, verification sample
datos/processed/   only the travel-time and terrain datasets (the rest is regenerated by the scripts)
salidas/           tables (CSV), figures, maps and model outputs reported in the article
docs/              REVISION_PASOS.md (step-by-step guide to the revision analyses)
busqueda/          literature search script and queries (Supplementary Section S9)
tests/             unit tests of the distance and desert-classification functions
```

## Data sources

| Source | Content | Terms |
|---|---|---|
| SUNEDU open data (cut-off 28 Aug 2024) | licensed undergraduate programmes with coordinates; institutional licensing; 2018 university identity cards | Peruvian open data (datosabiertos.gob.pe) |
| Minedu, ESCALE, 2025 Census of Education | 15,700 secondary schools, enrolment by grade, 934 non-university institutes | Peruvian open data |
| INEI | 2018 district poverty map; 2017 Census district tabulations (REDATAM); district boundaries | Peruvian open data |
| OpenStreetMap via Geofabrik | road and river network of Peru (extract downloaded 27 Sep 2026) | © OpenStreetMap contributors, ODbL 1.0 |
| Google Maps | car travel times for 58 school-campus pairs (calibration and verification; `datos/manual/`) | consulted 11-12 Oct 2026 |
| AWS Terrain Tiles (Terrarium) | elevation for the terrain check (step 36) | public dataset; sources include SRTM |

The OSM extract (`peru-latest.osm.pbf`, ~245 MB, SHA-256 `3e647828fba5b05150ec15c50926a679064ba6956160ad8a91f5b86508a4467e`) and the elevation tiles are not stored in the repository. Because OSM changes every day, travel-time results are stored in `datos/processed/` (`tiempos_colegios.csv`, `tiempos_colegios_escenarios.csv`, `tiempos_colegios_factor_regional.csv`, `accesibilidad_tiempo_distritos.csv`, `sensibilidad_colegios.csv.gz`), together with `relieve_colegios.csv`. With these files every table can be reproduced without downloading OSM or the elevation tiles.

## How to run

Python 3.10 or later.

```bash
pip install -r requirements.txt
python run_all.py                    # all default steps (a few minutes)
python run_all.py 25 27 28 29 30 24  # selected steps only
python run_all.py 4b 4d 26 31 32     # optional: rebuild and recalibrate travel times from a fresh OSM extract (30-60 min, ~3 GB RAM)
python run_all.py 36 34 37 35 38 28 30 24   # revision analyses (36 downloads elevation tiles; 37 takes 20-40 min)
```
